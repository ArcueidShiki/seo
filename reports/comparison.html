5. 在 Google 上验证排名：实验步骤

为什么今天还看不到 Google 排名：新站从提交到被收录通常要几天到几周，排名稳定还要更久。没有任何办法能在部署当天看到真实排名，所以我把实验设计成可以复现、可以记录的。
  1. 目标查询：vexlora position size calculator。"Vexlora" 是编造的品牌名，网上原本没有结果，所以这个查询下只有这两个 demo 在竞争，排名差异只来自 SEO 实现。另外观察非品牌查询 position sizing rules 1% risk（只有 Demo B 有对应页面）。
  2. 验证站点：在 Google Search Console 添加"网址前缀"资源 {{SITE_URL}}/，选 HTML 标记验证，把 token 设为环境变量 GSC_VERIFICATION 后重新构建部署（GitHub 仓库 Settings → Secrets and variables → Actions → Variables）。
  3. 提交 sitemap：在 GSC 里提交 {{SITE_URL}}/sitemap.xml（两个 demo 的 URL 都在里面）。
  4. 请求编入索引：用"网址检查"分别检查 {{SITE_URL}}/demos/before/ 和 {{SITE_URL}}/demos/after/，点"请求编入索引"。在"查看已抓取的网页 → 屏幕截图/HTML"里可以直接看到：Demo A 抓到的 HTML 几乎是空的。
  5. Bing：在 Bing Webmaster Tools 用"从 GSC 导入"一键添加；Bing 的数据也会供给 ChatGPT 搜索等 AI 产品。
  6. 记录：第 3、7、14、28 天分别搜索目标查询（用无痕窗口，地区设为 US），并查看 GSC → 效果 → 查询，把展示次数、点击、平均排名记录到下表。也可以用 site:arcueidshiki.github.io/seo/demos/ 查看收录了哪些页面。
