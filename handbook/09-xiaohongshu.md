# 小红书运营全指南

> 小红书不是朋友圈式的社交流，而是**搜索驱动的内容平台**。用户带着问题来搜，笔记被搜到后会长期带来流量。原文一位作者用约 6 个月从 0 涨到 1 万粉；另一篇经验文认为，小红书是国内最接近"搜索引擎"的内容平台。
> 本章顺序：定位 → 主页 → 选题 → 封面 → 标题文案 → 发布 → 涨粉 → IP → 变现 → 限流 → 工具。相关：抖音 / 视频见 [10](../10-douyin-video-wechat/)，引流漏斗见 [07](../07-launch-and-distribution/)。

## 1. 账号定位

### 1.1 定位是"关注者能得到什么"，不是"我是谁"

| 原则 | 说明 | 反例 → 正例 |
|---|---|---|
| 找到最自然的表达点 | 如果内容要"挤"才写得出来，说明定位错了 | 硬做读书号 2 周就停更 → 随手发的"租房省钱"反而爆了 |
| 回答"为什么关注我" | 定位描述的是用户收获 | "我是程序员" → "程序员的 10 分钟高效晚餐" |
| 敢于做小 | 具体比宽泛更好记、更易被关注 | "美食分享" → "只做泡面的 100 种吃法" |
| 用数据收窄 | 按互动数据持续微调方向 | 每月复盘爆款笔记 |
| 离钱近 | 优先选有搜索量、竞争小、容易变现的赛道 | 先想清楚以后卖什么 |

### 1.2 定位三问 + 九宫格

1. **受众是谁**：用户画像、需求场景。
2. **用什么内容 / 服务解决什么问题**：你交付的价值。
3. **最后卖什么**：变现产品（这一问必须写下答案）。

九宫格：中心是核心价值观，四周依次填写"我是谁（职业、外形、性格）""需要谁（粉丝画像、需求场景）""记忆点（一个词、口头禅、标志性道具）""差异化（优势、专业角度）""我能做什么（交付的价值）"。

### 1.3 两项检验

- **可持续**：能立刻列出 ≥ 30 个选题。
- **有区分度**：在小红书搜索你的细分词，直接竞品不多。

**一句话定位模板**：`给【谁】分享【什么具体内容】，让他们【得到什么结果】`。检验方法：陌生人读完简介和 3 篇笔记后，能说出你是做什么的。

原文的案例都只做一件事：

- "爱吃蛋"：只讲鸡蛋，比如鸡蛋煮几分钟最好，涨到约 48 万粉。
- "程序员豆腐"：每期介绍一个有趣的网站，连更 100 多期，内容短、信息密，真人出镜，涨到约 29 万粉。

## 2. 主页四件套：头像、昵称、签名、背景图

主页就是名片。在信息流里，用户点进主页前只能看到头像和昵称。

| 元素 | 要点 | 避免 |
|---|---|---|
| 头像 | 自然光下的清晰半身照（真人更容易建立信任），或统一风格的插画 / 虚拟 IP。原文作者换成白底半身照后，第二天多涨了几十个粉 | 合照、模糊、背景杂乱、侵权图片 |
| 昵称 | 好记、好搜，带上赛道词（例如"某某穿搭"）。常见组合：名字 + 性格 / 城市 / 职业 / 价值观 | 下划线、数字、emoji、生僻字（原文的"Lynn__2333🍒"搜不到）；"momo"这类泛名 |
| 签名 | 核心信息约 8–15 字。四要素：背景（如"90 后程序员"）、内容方向、一句钩子、商务邮箱。另一种公式：你是谁 → 一项成绩 → 关注能得到什么。不要谦虚 | 空泛口号；签名弱时，爆文也很难转化成粉丝 |
| 背景图 | 和内容调性一致（美食用餐桌图，旅行用风景），色调和头像统一 | 与定位无关的图片 |
| 主页封面墙 | 统一模板和色系，不要天天换风格 | 每篇封面风格都不一样 |
| "瞬间" | 当朋友圈用，发与定位相关的日常打卡 | — |

> ⚠️ 注意：联系方式只写邮箱。签名、笔记、评论里直接写微信号、手机号、二维码，很容易被判为站外导流（见第 11 节）。

## 3. 选题方法

### 3.1 好选题 = 用户需求 ∩ 你的优势

**五个选题来源**：

1. **搜索框下拉词**：例如输入"秋天穿搭"，会联想出"小个子 / 职场 / 显瘦"等长尾词，这些词自带流量。
2. **拆解同领域爆款**：看标题关键词、切入角度、形式（清单 / 测评 / 故事）。例如护肤类爆款常用"平价替代 / 避坑指南 / 好物推荐"。
3. **节日与购物节日历**：9 月秋冬穿搭需求上涨；618、双 11 发购物清单；520、七夕、圣诞、新年发礼物指南。原文一篇 520 约会穿搭的点赞是平时的 3 倍。
4. **评论区和私信**：粉丝追问的问题，原文中做成续篇后比原帖还火。
5. **跨平台**：微博热搜看趋势，抖音看什么内容最直观易懂，知乎看深度问题。

**选题池**（SOP 做法）：先攒 100 个选题，统计其中重复出现最多的关键词，那就是这个赛道的核心需求。

### 3.2 四项检验（全部通过才写）

| # | 检验问题 | 怎么验证 |
|---|---|---|
| 1 | 受众够大吗？ | 搜索下拉词多、相关笔记多 |
| 2 | 痛点是真的吗？ | 评论区有人在问、在抱怨 |
| 3 | 站内有热搜词或爆款吗？ | 搜索结果里有高赞笔记 |
| 4 | 我有资格说吗？ | 有亲身经历、实测、案例或独到观点 |

另外，内容至少要命中以下 4 项中的 2 项：**有用、有趣、有情绪价值、有品位 / 专业感**。

### 3.3 五种高表现选题类型（轮换使用）

| 类型 | 标题方向示例 |
|---|---|
| 清单 | "通勤包里的 10 件小物" |
| 避坑 | "租房前不看这 5 点会后悔" |
| 教程 | "3 步做出高点击封面" |
| 对比 | "百元 vs 千元，差别到底在哪" |
| 故事 | "从不看书到一年读完 10 本经典" |

**习惯**：看到有意思的评论立刻截图；每周末花 30 分钟研究搜索框和爆款；节日内容提前 1 周准备。系列选题动笔前，先用百度指数、360 趋势或 Google Trends 看近 12 个月的走势，平稳或上升才做。

## 4. 高点击率封面

原文认为，用户是否点开一篇笔记，约 80% 取决于封面：**封面决定点击，内容决定留存**。

### 4.1 CTR 基准（原文）

| 点击率 | 判断 | 动作 |
|---|---|---|
| < 3% | 差 | 必须换封面 / 标题 |
| ≥ 5% | 及格线 | 继续优化 |
| 8–15% | 同领域优秀创作者的常见水平 | 复用模板 |

### 4.2 三要素

1. **画面里有真人或真实场景**：同一个包，平铺拍点击率 3.6%，上身街拍 9%。
2. **短文字讲价值**：6–10 个字（工具篇的说法是 ≤ 10 字），颜色要和背景形成强对比，例如"30㎡小家收纳全攻略"。
3. **明亮干净**：避免大面积灰色和黑色；居中或对称构图，给文字留出位置。

### 4.3 检验与流程

- **缩略图测试**：缩到手机信息流里的最小尺寸，重点信息仍要看得清。
- **3 秒测试**：一个核心钩子，3 秒内能看懂，带冲突、对比或结果。封面的任务是被点开，不是好看。
- **流程**：拍 3–5 张光线好的清晰照片 → 选最能表达主题的一张 → 加标题字（简单设计、美图秀秀等）→ 保持版面干净，不铺满文字 → 在手机上预览。
- 每个封面至少花 10 分钟；全号使用统一模板，方便粉丝认出你；可以对封面做 A/B 测试。
- 原文改造案例：模糊截图 + 无字 + 杂乱背景，点击率 2.8% → 清晰实拍 + 8 字标题 + 统一背景，点击率 9.5%。

## 5. 爆款标题公式与文案

### 5.1 四个基础公式（附模板）

| 公式 | 模板 | 示例 |
|---|---|---|
| 数字 + 结果 | `【人群】+【数字】+【做法】+【结果】` | "小个子 3 套通勤穿搭，一周不重样" |
| 提问 | `为什么【常见做法】，却【反直觉结果】？` | "为什么天天护肤，皮肤却越来越差？" |
| 反差 | `【小投入】做出【大效果】` | "200 元改出 2 万的效果" |
| 情绪 | `别再【错误行为】了！【后果 / 解法】` | "别再乱买收纳盒了！3 个够用" |

**进阶公式**：

- **七要素公式**（SOP）：人群 + 场景 + 痛点 + 解决方案 + 情绪 + 行动号召 + 冲突，标题至少用上 4 个。例如"我踩过的 3 个坑，90% 新人都中招"。
- **二极管标题法**：
  - 正向刺激：方法 / 产品 + 极小的投入 + 夸张的结果；
  - 负向刺激：不做 X 就会后悔 + 紧迫感（利用损失厌恶）。

> ⚠️ 注意：标题的承诺必须在正文兑现。标题党会消耗信任，评论区一旦出现"标题党"就会伤害账号。避免虚假、绝对化的功效承诺。

### 5.2 改标题的威力（原文案例）

- "如何收纳小户型卧室"约 500 阅读 → 改成"30㎡ 能塞下 100 件衣服？"并改短句后约 2 万阅读，+300 粉。
- "小个子秋季穿搭分享"不到 800 阅读 → 加上"158cm、3 套、通勤、显高不踩雷"等具体信息后，2.5 万+ 阅读。

**规律**：越具体越好（身高、数字、时间、场景），并且把搜索下拉词放进标题。

### 5.3 正文写法

- 第一行直接点出痛点，让人留下来。
- 正文至少写 2 个具体的个人细节（数字、尺寸、时间、前后变化），用"聊天体"，不用"说明书体"。
- 结构：总-分-总，短段落，适量 emoji，体现人设和立场；发布前检查错别字。
- 结尾抛一个问题或给一个福利，引导评论（例如"要不要我整理一份清单？"）。
- 避免：广告腔（"强烈推荐""性价比超高"）、空洞开场、标题和内容不符、没有情绪。

### 5.4 20 种文案风格速查

| 风格 | 结构 |
|---|---|
| 种草 / 安利 | 痛点或真实使用 → 细节 / 对比 → 适合谁 + 价值 |
| 干货 / 教程 | 数字 + 关键词标题 → 清晰步骤 → 引导收藏关注 |
| 反差 | 冲突 → 转折 → 呼应 |
| 前后对比 | 先放结果 → 讲方法 → "你也可以" |
| 模板清单 | 可直接套用的清单，主打被收藏 |
| 踩坑避雷 | "千万别买 / 别做" + 原因 |
| 低成本 / 平替 | 便宜方案达到同等效果 |
| 挑战打卡 | 30 天挑战 + 每日清单 |
| AIGC 效率风 | 冷静、高效，例如"三个工具解决九成问题" |
| 打脸反转 | "我以前也觉得……直到……" |
| 其余 10 种 | 情绪共鸣、搞笑、故事纪录片、揭秘、人设标签、时光记录、新手心声、情境代入、自我对话、反套路 |

**迭代**：每篇发完看点击率、互动率、转化率，维护一份"本号高效词表"（原文作者的是"省钱 / 小个子 / 通勤"），每月更新一次。

## 6. 发布策略与频率

### 6.1 形式

- **图文**：适合清单、教程、测评，门槛低，容易被收藏。
- **视频**：适合氛围和场景展示，制作成本高。
- **组合打法**：先用一篇图文讲清思路，下一篇用视频展示结果。

### 6.2 发布时间（三篇文档的说法）

| 来源 | 工作日 | 周末 |
|---|---|---|
| 内容发布策略 | 12:00、20:00–22:00 | 10:00、21:00 前后 |
| 涨粉技巧 | 12:00、20:00–22:00 | 10:00–11:00 |
| 图文笔记 SOP | 8–10 点、12–14 点、18–22 点任选 | 同左 |

原文对比：同一篇内容早上 7:30 发不到 200 阅读，周五晚 9 点发 5000+。三份时间表都覆盖了午间和晚间，可以先按这两个时段发，再用自己的数据校准。

### 6.3 频率

- 新号：每周 3–4 篇。稳定期：每周 2 篇高质量 + 1 篇轻内容。
- 稳定持续比集中爆发更有效。
- 至少坚持"每周 ≥ 3 篇 × 3 个月"再判断成败。原文的说法是：一篇不火发十篇，十篇不火发五十篇。

## 7. 图文笔记创作 SOP

1. **选题**：从选题池里挑出通过"四项检验"的题。
2. **拍摄前定 4 个要素**：主题、场景、风格、形式（干货 / 经验 / 对比）。
3. **图片优先，文字为辅**：产品图 + 过程图、前后对比、结果图、细节图。
4. **封面**：按第 4 节检查。
5. **标题**：写 2–3 个备选，找 3 个人投票。
6. **正文**：按第 5.3 节写，总-分-总，检查错别字。
7. **标签**：1 个核心关键词标签 + 1 个热门话题标签 + 1 个垂直细分标签。标签是为了被搜到，不在于数量多。
8. **敏感词扫描**（第 12 节）。
9. **发布**：选一个高峰时段；商家 / 接单类账号要加定位。
10. **评论区运营**：当天回复评论；引导领取资源或模板。
11. **7 天复盘**：浏览、点赞 / 评论 / 收藏，**搜索流量与推荐流量的占比**；写下这篇"什么有效、什么拖后腿、下一篇改什么"。

> ⚠️ 注意：原 SOP 建议发布后"用小号在评论区带节奏"。这和限流文档"一机一号、避免多账号"的原则冲突，也属于平台禁止的虚假互动，**不建议**。评论区引导用主号自己的置顶评论来做。

## 8. 从 0 到 1 起号手册

| 阶段 | 时间 | 重点 | 目标 |
|---|---|---|---|
| 探索 | 第 1–2 月 | 定位、主页四件套；每周 3–4 篇；尝试 2–3 种风格 | 找到点击率 ≥ 5% 的封面 / 标题模式 |
| 定型 | 第 3–4 月 | 固定人设、视觉模板、系列栏目 | 0 → 约 3k 粉，只做内容 |
| 系统化 | 第 5–6 月 | 系统地产出内容和故事；接小品牌合作 | 约 5k 粉时有第一笔广告收入 |
| 产品化 | 第 7–9 月 | 推出自有付费内容（清单、模板、课程） | 第二条收入线 |
| 稳定 | 第 10 月起 | 品牌合作、自有产品、引流三条线并行 | 稳定增长 |

**起号的内容生产**：用模板工具提高效率。原文还提到"参考爆款封面生成相似封面""文案仿写"。

> ⚠️ 注意：仿写只能学结构和角度，不能照搬文字和图片。非原创是导致不被收录（掉收录）的原因之一（见第 11 节），也可能涉及侵权。

## 9. 涨粉技巧

1. **收藏型"资源钩子"**：例如"50 个封面制作工具""10 套上班穿搭"。很多人怕错过而收藏，即使以后不再翻看。收藏会提升分发。每周至少发 1 篇。
2. **做连载系列**：统一的封面和标题格式，让人为了下一期关注你。
3. **真人出镜**：带人脸的视频流量更好。
4. **信息密度高、节奏快**：程序员豆腐的成功因素是单一精准的定位、真人出镜、快剪辑、真实的主页、系列化。
5. **互动**：结尾提问或给福利；24 小时内回复评论（算法会看点赞、收藏、评论、关注）；关注同行学习；参加官方话题活动拿曝光。
6. **每周数据诊断**：见下表。

### 9.1 数据诊断矩阵（两篇文档的口径不同，合并如下）

| 现象 | 诊断 | 动作 |
|---|---|---|
| 曝光高，点击率低 | 封面 / 标题没抓住人 | 换封面，重写标题 |
| 点击高，点赞收藏评论少 | 内容没兑现标题承诺，或价值不足 | 加干货密度、具体细节 |
| 曝光低，但看过的人互动率高 | 内容好，没被分发 / 搜到 | 标题和正文补搜索关键词，换封面重试 |
| 收藏远高于点赞（如 2000 曝光、400+ 收藏） | 实用型内容 | 拆成系列续篇（原文从一篇做成了 3 篇） |

> ⚠️ 注意："曝光高 + 互动低"这个现象，《内容发布策略》判为"标题好、内容弱"，《运营必备工具》判为"封面 / 标题问题"。分歧来自它们没有区分"曝光 → 点击"和"点击 → 互动"两个环节。按上表先看点击率，再看互动率，就能消除歧义。

## 10. 真实感 IP 与内容配比

**三个特征**：

- **可识别**：头像、昵称、封面风格、文案语气保持一致。
- **有温度和故事**：分享个人经历、感受、偏好。
- **有价值**：提供知识、经验、工具或娱乐。

**打造方法**：

- 写一句人设陈述：我是谁、擅长什么、什么语气。
- 统一视觉规范：封面配色、字体、版式、滤镜。
- 用第一人称讲故事，持续输出价值，根据粉丝反馈调整。
- 原文案例"简小喵"：卡通猫 IP 贯穿头像、封面和插图，用幽默的文案推荐设计和 AI 工具，辨识度很高。

**不要做**：

- 完全虚构的人设，被拆穿后信任崩塌；
- 追求完美（小失误反而拉近距离）；
- 成熟后频繁改变风格。

### 10.1 内容配比：5-3-2

| 比例 | 内容 | 作用 |
|---|---|---|
| 50% | 与定位强相关的垂直内容 | 让算法和用户给你打上清晰的标签 |
| 30% | 相邻 / 延伸内容 | 拓宽账号边界 |
| 20% | 个人生活 | 展示账号背后的人 |

每月按标签统计实际比例，偏差控制在 ±10% 以内。

> 提醒：社交引流篇的 80/10/10（有用 / 产品 / 个人）是按"用途"划分，5-3-2 是按"主题"划分，两者可以叠加使用。

## 11. 限流（流量异常）与检测

小红书官方的说法是"流量异常"，不叫"限流"。判断时**只和自己账号的历史基线比**。

### 11.1 类型与阈值

| 类型 | 表现 |
|---|---|
| 单篇异常 | 浏览量远低于平均（例如平时 1000，这篇只有 40–50）；或者互动突然停止、浏览断崖下跌 |
| 账号异常 | 近期所有笔记都很差；或者无法点赞、评论（被禁言 / 限制）。封禁通常会收到站内信，但也存在静默限流 |
| 经验阈值 | **发布 24 小时后浏览 < 50**，大概率异常（对平时上千浏览的老号尤其明显） |

### 11.2 三个自检方法

1. **分享测试**：把笔记转发到微信打开。如果提示"笔记正在审核"或"无法展示"，说明没过审或受限。常见原因：违禁 / 敏感词、低俗内容、站外导流。
2. **搜号测试**：**用另一个账号**搜你的小红书号，正常时会显示主页卡片和笔记。自己的账号能看到自己的内容，没有参考意义。
3. **搜标题测试**：用另一个账号搜笔记的完整标题，切换"最新"和"最热"排序，看能不能搜到。

### 11.3 不被收录（掉收录）的原因

账号违规；笔记太旧；仍在审核中；非原创；标题和正文里没有关键词；关键词堆砌。

### 11.4 处理

- **知道违规点**：直接编辑修改（会重新进入审核）。
- **不知道违规点**：删掉，不要盲改（改错了会再次触发违规）。
- **账号违规**：停止违规行为（站外导流、未报备的软广），正常发几篇笔记，通常 7 天左右恢复。
- **处罚逐级加重**：例如禁言 2 天 → 7 天 → 1 个月 → 封号。
- **一机一号**：同一台手机来回切账号，容易被识别为营销号；一个号被封，可能牵连同设备的其他账号。

## 12. 敏感词

发布前**每一篇**都做敏感词扫描（例如简单设计的免费敏感词检测，会高亮违禁词），零高亮再发。重点排查：

| 类别 | 例子 | 依据 |
|---|---|---|
| 站外导流 | 微信号、二维码、网址、"私信领取""加 V" | 原文：导流是常见违规原因 |
| 广告腔 / 软广 | "强烈推荐""性价比超高"、未报备的商业合作 | 原文：广告腔和软广 |
| 绝对化用语 | "最好""第一""国家级"等 | 通用：《广告法》禁止绝对化用语 |
| 功效夸大 | 医疗、减肥、美白的确定性承诺 | 通用：平台对功效宣称审核严格 |
| 低俗 / 擦边 | — | 原文：未过审原因之一 |

## 13. 变现策略

| 路径 | 起点 | 做法 | 原文数据 |
|---|---|---|---|
| 品牌合作 | 约 1k–5 万粉的小号也可以接 | 只接和账号调性相符、自己用过的产品；先讲痛点，再引出产品，保持真实 | 作者 3k 粉时接第一单，互动比平时高 50%，+200 粉 |
| 自有产品 / 服务 | 约 1k 有互动的粉丝即可 | 清单、模板、课程、咨询、周边、店铺链接 | 1k 粉时卖付费"小个子通勤清单"，一周卖出 20 份 |
| 引流变现 | 有稳定内容后 | 结尾自然地给出口；免费资料 → 小程序 / 私域 → 付费内容；配合优惠券、限时优惠 | — |

原文案例：参考答案阅览室（读书会员，销售额超千万）；一个 iPhone 快捷指令记账工具（零开发成本，把成熟方案包装好，卖得很好）。

> ⚠️ 注意：商业合作建议走小红书官方的蒲公英平台报备。未报备的软广是账号违规的常见原因。引流话术越"硬"，限流风险越高，详见第 11、12 节。

## 15. 检查清单

- [ ] 一句话定位写好，能列出 ≥ 30 个选题
- [ ] 昵称带赛道词、无数字下划线；签名四要素齐全；联系方式只写邮箱
- [ ] 每篇的选题都来自搜索下拉词或爆款，并通过四项检验
- [ ] 封面有真人或真实场景，6–10 字对比色文字，通过缩略图测试；点击率 < 3% 的笔记换封面
