用 auditor 审计你自己的网站

git clone https://github.com/ArcueidShiki/seo && cd seo && npm ci
node auditor/audit.mjs --url https://你的网站/ --name mysite --keyword "你的主关键词"
# 输出 reports/mysite.json：逐条 pass/fail + Lighthouse + 搜索结果片段预览
