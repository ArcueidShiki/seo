# 小红书运营：定位、选题、封面、文案、限流与变现

> 一句话：把小红书当作搜索驱动的内容平台来运营，帮用户产出定位、选题池、封面标题文案、发布日历，并诊断数据和限流。完整内容见仓库 `handbook/09-xiaohongshu.md`（ArcueidShiki/seo）。

## 何时使用

- 用户要开新号 / 起号，或问账号定位、昵称、签名、头像怎么写
- 用户要选题、写笔记、做封面、起标题，或要一份 30 天发布日历
- 用户的笔记点击率低、互动低、曝光低，要做数据诊断
- 用户怀疑被限流、掉收录、笔记审核不过，或想做敏感词检查
- 用户问小红书怎么变现、接品牌合作、卖自有产品

## 核心原则

1. 小红书是搜索驱动平台：选题来自搜索下拉词，标题和正文要含搜索长尾词，笔记被搜到后会长期带流量。
2. 定位写"关注者能得到什么"而不是"我是谁"，敢于做小；能立刻列出 ≥ 30 个选题，且搜细分词时直接竞品不多。
3. 封面决定约 80% 的点击：CTR < 3% 必须换封面 / 标题，≥ 5% 是及格线，8–15% 是同领域优秀水平。
4. 封面三要素：真人或真实场景、6–10 字（≤ 10 字）强对比价值文字、明亮干净；必须过缩略图测试和 3 秒测试。
5. 标题用一种公式（数字 + 结果 / 提问 / 反差 / 情绪；七要素至少用 4 个），越具体越好，承诺必须在正文兑现。
6. 正文第一行点痛点，至少 2 个具体个人细节，聊天体、总-分-总，结尾提问或给福利；24 小时内回复评论。
7. 标签只用 3 个：1 个核心关键词 + 1 个热门话题 + 1 个垂直细分。
8. 先在午间 12:00 和晚间 20:00–22:00 发，再用自己的数据校准。
9. 新号每周 3–4 篇；稳定期每周 2 篇高质量 + 1 篇轻内容；至少"每周 ≥ 3 篇 × 3 个月"再判断成败。
10. 内容配比 5-3-2（垂直 / 延伸 / 个人生活），每月核对，偏差控制在 ±10% 内；每周至少 1 篇收藏型"资源钩子"。
11. 每篇发布前做敏感词扫描，零高亮再发；联系方式只写邮箱；一机一号。
12. 限流只和自己账号的历史基线比；发布 24 小时后浏览 < 50 大概率异常，走自检流程；商业合作走蒲公英报备。

## 操作流程

1. **收集信息**：赛道、个人优势与经历、最后要卖什么、能否真人出镜、每周可投入时间；已有账号则要粉丝数、篇数和近 10 篇数据（曝光、点击率、点赞 / 收藏 / 评论、搜索流量与推荐流量占比）。
2. **定位**：用"定位三问"（受众是谁 / 解决什么问题 / 最后卖什么）+ 九宫格，产出一句话定位，并做两项检验（≥ 30 选题、竞品不多）。
3. **主页四件套**：给出 3 个昵称候选（带赛道词）、签名（核心 8–15 字，含背景 / 内容方向 / 钩子 / 商务邮箱）、头像与背景图建议、封面墙统一模板。
4. **建选题池**：从搜索下拉词、同领域爆款、节日与购物节日历、评论区与私信、跨平台（微博 / 抖音 / 知乎）五个来源攒题；每题过"四项检验"并命中"有用 / 有趣 / 情绪价值 / 品位专业感"中至少 2 项；按清单 / 避坑 / 教程 / 对比 / 故事五类轮换。
5. **单篇生产**：按 11 步 SOP 输出封面文字、2–3 个标题备选、正文、3 个标签、发布时段、置顶评论引导语。
6. **排日历**：按起号阶段产出 30 天日历（每周 3–4 篇、5-3-2 配比、每周 ≥ 1 篇资源钩子、节日内容提前 1 周准备）。
7. **数据诊断**：先看点击率再看互动率，用诊断矩阵判断卡在"曝光 → 点击"还是"点击 → 互动"，给出逐篇动作；做 7 天复盘。
8. **限流 / 收录排查**：分享测试、搜号测试、搜标题测试（后两项必须用另一个账号），对照掉收录原因给出处理方式。
9. **变现**：按粉丝量和互动匹配品牌合作 / 自有产品 / 引流变现路径，提醒报备与导流风险。

## 关键数字与门槛

| 指标 | 门槛/建议值 | 说明 |
|---|---|---|
| 封面点击率 | < 3% 差 / ≥ 5% 及格 / 8–15% 优秀 | < 3% 必须换封面或标题 |
| 封面文字 | 6–10 字（≤ 10 字） | 与背景强对比 |
| 封面制作 | 每个至少 10 分钟 | 先拍 3–5 张再选 |
| 签名核心信息 | 约 8–15 字 | 四要素：背景、方向、钩子、邮箱 |
| 定位检验 | ≥ 30 个选题 | 选题池目标 100 个 |
| 标签 | 3 个 | 核心 + 热门 + 细分 |
| 发布时段 | 工作日 12:00、20:00–22:00；周末 10:00、21:00 前后 | 再用自己的数据校准 |
| 新号频率 | 每周 3–4 篇 | 稳定期 2 篇高质量 + 1 篇轻内容 |
| 判断成败 | 每周 ≥ 3 篇 × 3 个月 | 一篇不火发十篇 |
| 内容配比 | 50% / 30% / 20% | 偏差 ±10% |
| 评论回复 | 24 小时内 | 算法看赞藏评关注 |
| 资源钩子 | 每周 ≥ 1 篇 | 收藏提升分发 |
| 限流阈值 | 发布 24 小时浏览 < 50 | 对平时上千浏览的号尤其明显 |
| 违规恢复 | 约 7 天 | 处罚逐级：禁言 2 天 → 7 天 → 1 个月 → 封号 |
| 品牌合作起点 | 约 1k–5 万粉 | 原文 3k 粉接第一单 |
| 自有产品起点 | 约 1k 有互动粉丝 | 原文 1k 粉一周卖出 20 份清单 |

## 模板与示例

**一句话定位**：`给【谁】分享【什么具体内容】，让他们【得到什么结果】`（检验：陌生人看完简介和 3 篇笔记能说出你做什么）

**标题公式**

| 公式 | 模板 | 示例 |
|---|---|---|
| 数字 + 结果 | 【人群】+【数字】+【做法】+【结果】 | 小个子 3 套通勤穿搭，一周不重样 |
| 提问 | 为什么【常见做法】，却【反直觉结果】？ | 为什么天天护肤，皮肤却越来越差？ |
| 反差 | 【小投入】做出【大效果】 | 200 元改出 2 万的效果 |
| 情绪 | 别再【错误行为】了！【后果 / 解法】 | 别再乱买收纳盒了！3 个够用 |
| 七要素 | 人群 / 场景 / 痛点 / 方案 / 情绪 / 行动号召 / 冲突，至少 4 个 | 我踩过的 3 个坑，90% 新人都中招 |

**单篇 SOP（11 步）**

```
1 选题（过四项检验）  2 定主题 / 场景 / 风格 / 形式  3 图片优先：产品图、过程图、前后对比、细节
4 封面（三要素 + 缩略图测试）  5 标题 2–3 个备选，找 3 人投票  6 正文总-分-总，查错别字
7 标签 1 核心 + 1 热门 + 1 细分  8 敏感词扫描零高亮  9 高峰时段发布（商家加定位）
10 当天回复评论，主号置顶评论引导  11 7 天复盘：赞藏评 + 搜索 / 推荐流量占比 + 下一篇改什么
```

**数据诊断矩阵**

| 现象 | 诊断 | 动作 |
|---|---|---|
| 曝光高，点击率低 | 封面 / 标题没抓住人 | 换封面，重写标题 |
| 点击高，赞藏评少 | 内容没兑现标题或价值不足 | 加干货密度和具体细节 |
| 曝光低，看过的人互动高 | 内容好但没被分发 / 搜到 | 补搜索关键词，换封面重试 |
| 收藏远高于点赞 | 实用型内容 | 拆成系列续篇 |

**起号阶段**

| 阶段 | 时间 | 目标 |
|---|---|---|
| 探索 | 第 1–2 月 | 试 2–3 种风格，找到点击率 ≥ 5% 的封面 / 标题模式 |
| 定型 | 第 3–4 月 | 固定人设、视觉模板、系列栏目；0 → 约 3k 粉 |
| 系统化 | 第 5–6 月 | 约 5k 粉时第一笔广告收入 |
| 产品化 | 第 7–9 月 | 自有付费内容（清单 / 模板 / 课程） |
| 稳定 | 第 10 月起 | 品牌合作 + 自有产品 + 引流三线并行 |

**限流三项自检**：分享到微信打开是否提示审核中 / 无法展示 → 另一账号搜你的小红书号 → 另一账号按完整标题搜笔记（切换"最新""最热"）。

## 常见错误与风险

- ⚠️ 签名、笔记、评论里写微信号、手机号、二维码、网址、"私信领取""加 V"：判为站外导流，单篇或整号限流。
- ⚠️ 未经蒲公英报备的软广、广告腔（"强烈推荐""性价比超高"）。
- ⚠️ 绝对化用语（"最好""第一""国家级"）和医疗、减肥、美白的确定性功效承诺。
- ⚠️ 用小号在评论区带节奏：属于虚假互动，且违反一机一号原则，不做；用主号置顶评论引导。
- ⚠️ 仿写照搬文字和图片：非原创会掉收录，还可能侵权；只学结构和角度。
- ⚠️ 标题党：评论区出现"标题党"会伤害账号。
- ⚠️ 不知道违规点就盲改：会再次触发违规，应直接删除。
- ⚠️ 同一手机来回切多个账号：易被识别为营销号，一号被封可能牵连其他账号。
- ⚠️ 昵称带下划线、数字、emoji、生僻字，或用"momo"这类泛名：搜不到、记不住。
- ⚠️ 完全虚构人设、追求完美、成熟后频繁换风格。
- ⚠️ 低俗擦边内容；关键词堆砌或标题正文无关键词，都会导致不被收录。

## 交付格式

- 定位与主页：`项目 | 建议 | 理由` 表，附一句话定位与 3 个昵称候选。
- 选题池 / 日历：`日期 | 选题 | 类型 | 5-3-2 类别 | 搜索词 | 封面文字 | 标题 | 发布时段`。
- 单篇：封面文字、标题备选（标注所用公式）、正文、标签、置顶评论，并附敏感词自查结果。
- 诊断：逐篇 `笔记 | 曝光 | 点击率 | 互动率 | 诊断 | 动作 | 优先级`；限流判断给出"大概率 / 可能 / 不太可能"及依据，不编造精确概率。
