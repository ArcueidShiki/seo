# 独立开发者方法论与案例

> 一句话：帮用户用"缩小到能做第一"的思路选方向、评估点子、定位产品，并建立可复盘的增长系统。完整内容见仓库 `handbook/13-mindset-and-case-studies.md`（ArcueidShiki/seo）。

## 何时使用

- 用户不知道做什么产品，想找小众市场或验证一个点子
- 用户有产品点子，想用关键词数据判断值不值得做
- 用户要写品类定位、产品哲学、"我们不做"清单，或思考如何对抗大公司
- 用户问独立开发者的节奏：同时做几个产品、多久见效、什么时候换方向
- 用户要写一篇内容前的"打败 SERP"简报，或想参考成功的 SEO 小工具案例和学习资源

## 核心原则

1. 做产品和做营销同等重要：启动时预留约 30% 预算做推广（原文电商例）；产品差、营销猛，差评会反过来侵蚀流量。
2. 流量赢家通吃：TOP1 约 70%+、TOP2 约 25%+、其他约 5%；缩小范围，直到你能在细分领域做到第一。
3. 100 个打 90 分的用户胜过 1 万个打 60 分的用户；只有能写出全网该话题最好的页面时才写。
4. 关键词选点子（Danny Postma 模式）：KD < 20（前 10 名约只需不到 10 条外链）、月搜索量 > 500、相关词 > 100；搜索量接近零意味着要自己创造市场，对独立开发者不利。
5. 零竞争是危险信号；SERP 广告多说明付费竞争激烈；Trends 曲线平稳或稳步上升才做，避开昙花一现的潮流。
6. 垂直定位："AI 婚纱照"而不是"AI 文生图"；对领域的理解要到 90 分，60 分不够。
7. 没方向就看空闲时间花在哪；还没有就模仿一个已验证赚钱的产品，把获客到变现的闭环跑一遍（"先上牌桌"）。
8. 验证两指标：留存 4-2-1（D1/D7/D30 ≥ 40%/20%/10%）+ 单次访问收益 ≥ CPC，都达标再花钱请 KOL。
9. 一次只做一个产品，做到有自然收入再开下一个；长期押注一个方向，每 1–2 年换一次方向不会有大结果。
10. 护城河不靠功能、价格、体验，而靠长期押注、开源深度创新、开放免费、鲜明产品哲学、少即是多、窄门。
11. 产品哲学 = 3 个关键词 + 一份"我们不做"清单；流量追随"可讨论性"（极致、独特、名字好记）。
12. 预期：Google 约 3 个月开始给流量，SEO 至少 6 个月见效；认真计划，但不要卡在计划里。

## 操作流程

1. **收集信息**：兴趣与专长、空闲时间花在哪、可投入时间与预算、技术能力、目标市场（国内 / 出海，两者没有高下之分）、已有点子或产品、变现预期。
2. **无方向时走七步小众市场法**：兴趣清单 → 真实问题清单（记录用户原话）→ 竞品表 → 关键词表 → 机会评分 → 一句话 USP → 小规模测试（预售页 / 等待名单）。每步给出产出物。
3. **有点子时做关键词评估**：用 Postma 门槛判断 KD、搜索量、相关词数；查 Trends 走势；数 SERP 广告；判断能否在细分做到 TOP1，不能就继续缩小范围。
4. **域名与页面骨架**：域名短、清楚、含主关键词；主关键词进 H1（全站每页唯一）、title、description、图片文件名和 alt；规划子关键词页与博客。
5. **定位**：写品类定位句、产品哲学（3 关键词 + 不做清单），从护城河表中选 1–2 条作为长期押注。
6. **内容简报**：每篇动笔前填"打败 SERP"简报，说明前 3 名的缺点和你的增量。
7. **增长系统**：按 6 步循环产出目标、问题清单（区分致命问题和琐事）、可委托 / 自动化项、月度复盘模板。
8. **第一年 SEO 路线图**：按三阶段（技术 SEO → 关键词 + 优质内容 → 监控与外链）排时间。
9. **案例对标**：从 23 个案例中挑 2–3 个与用户方向相近的，说明可借鉴点，并建议先读该领域 2–3 篇拆解。
10. **交付**：机会评分表 + 推荐与概率判断。

## 关键数字与门槛

| 指标 | 门槛/建议值 | 说明 |
|---|---|---|
| 营销预算 | 启动预算的约 30% | 原文电商例 |
| 流量份额 | TOP1 约 70%+ / TOP2 约 25%+ / 其他约 5% | 另一篇称第一名拿走 95% 以上 |
| KD | < 20 | 前 10 名约需不到 10 条外链 |
| 月搜索量 | > 500 | 接近零 = 自己创造市场 |
| 相关词 | > 100 个 | 能扩出子页面 |
| 理解程度 | 90 分 | 60 分不够 |
| 用户质量 | 100 个 90 分用户 > 1 万个 60 分用户 | 前者会自发传播 |
| 留存 | D1/D7/D30 ≥ 40%/20%/10% | 达标后再请 KOL |
| 单次访问收益 | ≥ CPC | 同上 |
| Google 起量 | 约 3 个月 | 上线前装好 GA 和 GSC |
| SEO 见效 | 至少 6 个月 | 外链从 80 到 90 分约 6 个月 |
| 技术 SEO | 约 60 分，一周学会、几周做完 | ROI 最高 |
| 深度文章 | 先写约 10 篇，每 2–3 周 1 篇 | 达到约 70 分 |
| 专业改写 | 约 $200/篇（Upwork） | AI 起草 + 自改 1 小时 |
| 转载 | 收录后转前约 70% 到 Medium | 文末链回原文 |
| MVP | 借助 AI 约 3 小时可行 | 原文 |
| 换方向 | 每 1–2 年换一次 = 难有大结果 | 长期押注 |

## 模板与示例

**品类定位句**：`我们要成为【哪个细分品类】的第一，和现有领导者的区别是【X】`（放进首页 H1 或标语）

**产品哲学**：`3 个关键词 + 我们不做：【A】【B】【C】`（例：小报童只做付费内容，不做社区、广告、算法推荐）

**"打败 SERP"简报**

| 项 | 内容 |
|---|---|
| 目标词 / 意图 | 如 "pdf to excel bank statement" / 工具 + 教程 |
| 前 3 名的缺点 | 没有真实截图、步骤缺失、内容过时 |
| 我们的增量 | 实测数据、可交互工具、对比表、更新到今年 |
| 页面类型 | 与 SERP 主流一致（工具页 / 教程 / 对比） |
| 证据 | 截图、数字、失败案例（E-E-A-T） |

**七步小众市场法**

| 步 | 做什么 | 产出 |
|---|---|---|
| 1 | 从兴趣出发，可组合兴趣 | 兴趣清单 |
| 2 | 读 Quora、论坛、评论区，访谈，找"太贵 / 太麻烦" | 问题清单（原话） |
| 3 | 分析竞品内容、质量、受众、互动；数 SERP 广告 | 竞品表 |
| 4 | Trends、关键词规划师、Ubersuggest、Semrush、Ahrefs | 关键词表 |
| 5 | 能否赚钱（畅销榜、Exploding Topics、ClickBank）、受众、是否长青 | 机会评分 |
| 6 | 利用竞品弱点 + 独特专业能力 + 微细分 | 一句话 USP |
| 7 | 预售页 / 等待名单，兴趣低时 A/B 测试 | 预订数 / 注册数 |

**增长系统循环**

```
定目标 → 列问题 → 排优先级并逐个解决 → 执行 → 委托 / 自动化 → 用结果校正 →（回到列问题）
例：目标"6 个月 1 万粉 + 月入 X"；致命问题"内容质量差"；琐事"用手机还是电脑做"；
    自动化"RSS 收集素材、定时发布"；每月复盘写下最大瓶颈和调整措施
```

**护城河速查**

| 护城河 | 例子 |
|---|---|
| 长期押注一个方向 | DeepSeek / 幻方长期投入 GPU；字节坚持推荐算法 |
| 鲜明产品哲学 | 只保留 24 小时的日记 App；小报童只做付费内容 |
| 少即是多 | 大疆 = 无人机；钱迹持续迭代记账 |
| 窄门 | 先做细分头部再扩张，选比大公司更窄的赛道 |
| 开源深度创新 / 开放免费 | 站在开源上做深工程；用免费换规模和口碑 |

**案例规律**：需求窄而清楚、搜索意图强的单一功能小工具（PDF、去水印、图片翻译、图表生成、测试类）往往排名好也赚钱。例：单页网站月访问 10 万、月利润 $5k；"无聊" PDF 工具 $4 万/月；AI Graph Maker 月访问 5 万、年入 $2–3 万；心理测试网站月访问 310 万。

## 常见错误与风险

- ⚠️ 追最大的词、做宽泛赛道（"AI 文生图"）与大厂正面竞争。
- ⚠️ 选零竞争或只有单一尖峰的潮流词（如指尖陀螺式热点）。
- ⚠️ 同时开多个产品、频繁换方向；或卡在计划里迟迟不动手。
- ⚠️ 把内容锁在注册或付费墙后面，落地页不能立刻满足需求。
- ⚠️ parasite SEO（寄生在高权重站点发内容）：属于 Google 2024 年起打击的站点声誉滥用。
- ⚠️ 付费让网站转载并加链接却不标 `rel="sponsored"`：违反垃圾政策。
- ⚠️ "竞品 + 免费优惠券"页面没有真实优惠：误导用户。
- ⚠️ 用 GPTZero 压到 40% 以下作为发布标准：不可靠；Core Web Vitals 的 FID 已于 2024 年 3 月被 INP 取代。
- ⚠️ 接码平台（虚拟手机号）批量注册第三方平台：可能违反服务条款导致封号，不推荐。
- ⚠️ 过期域名买之前不查历史；工具价格（Semrush / Ahrefs 试用价）已过时，以官网为准。

## 交付格式

- 方向 / 点子评估：`候选方向 | 搜索量 | KD | 相关词 | 趋势 | 竞争 / 广告 | 变现路径 | 能否做到细分 TOP1 | 优先级(P0/P1/P2)` 表，未知数据标"待查"而不是编造。
- 每个候选给成功可能性（高 / 中 / 低）和主要依据、最大风险、下一步最小验证动作。
- 定位产出：品类定位句、产品哲学、选定护城河；增长系统产出：目标、问题清单（致命 / 琐事）、月度复盘表。
