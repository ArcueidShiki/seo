# 关键词研究与选题

> 一句话：帮用户从一个种子词出发，按阶段门槛和 SERP 实况选出"能赢的词"，并落成一页一词规划表。完整内容见仓库 `handbook/01-keyword-research.md`（ArcueidShiki/seo）。

## 何时使用
- 用户给新产品 / 新站定方向，问"这个词能不能做""KD 多少算低""搜索量够不够"
- 用户要给已有产品定 5 个核心词，或扩一批长尾 / 文章选题
- 用户贴出 Semrush / Ahrefs / GSC / Keyword Planner 数据，要你打分、排序、选词
- 用户要找竞品词（alternatives / vs / coupon / free）或最近上升的新词
- 用户发现多个页面争同一个词（关键词蚕食），需要重做关键词 → URL 映射
- 用户要规划程序化页面，或小红书 / 抖音 / 知乎等平台的站内长尾清单

## 核心原则
1. **先有搜索需求，再有页面**：每个页面都要对应真实查询（工具数据或搜索框联想词），凭灵感的选题一律退回。
2. **一页一词**：一个页面只服务一个主关键词 + 近义词和长尾；同一主关键词在规划表里只能出现一次。
3. **按场景用门槛**：新站方向 KD < 20、月搜索量 > 500、相关词 > 100；已有产品核心词 KD < 50、搜索量 ≥ 1,000（理想值）。
4. **5 个核心词难度要高低搭配**，至少 1 个能较快冲进前 3，用来拿第一批流量。
5. **已有站点先吃"差一口气"的词**：GSC / Bing 里已有曝光、平均排名约 11–30 的查询，不看 KD。
6. **数据只说明"有没有人搜"，能不能做必须看 Top-10 SERP**；写不出"比现在第一名更好"的理由就先不写。
7. **页面类型跟着 SERP 走**：Top 10 是教程 / 清单就别拿产品页硬拼；Top 10 是工具页就别只写一篇文章。
8. **同一张表只用一个工具的 KD 和搜索量**：Ahrefs 和 Semrush 算法、数据库不同，不能横比，换工具要重新校准。
9. **Parent Topic 和已有页面主词相同 → 并入已有页面**，不再单独开新页。
10. **看 12 个月和 5 年曲线**：持平或稳步上升才通过；一次性尖峰后快速回落的放弃。
11. **垂直优先，做不到第一就继续缩小范围**：宁可在更窄的话题第一，也不要在大词里排第十五。
12. **2026**：AI Overviews / AI Mode 让 "what is X" 类信息查询点击率明显下降，选词时给任务型、工具型、对比型、场景型词更高权重。

## 操作流程
1. **收集输入**：产品核心功能、目标市场与语言（Google / 百度 / 平台站内）、站点阶段（DR≈0 的新域名还是已有流量）、用户能用的工具（Semrush / Ahrefs / GSC / 只有免费工具）、已上线页面清单。缺数据时先问，不要编数字。
2. **定种子词**：从产品核心功能出发，例如 `text to speech`。
3. **扩词**：Google 自动补全 + 结果页底部"相关搜索"；由你列出相关词、同义词、用户会问的问题；Semrush / Ahrefs 的 Related / Matching terms。
4. **三层扩展**：L1 核心词 → L2 场景词（核心词 + 场景 / 人群 / 平台）→ L3 问题 / 对比 / 教程词（best…、how to…、X vs Y）。
5. **挖上升词**：词根法组合；在 Google Trends 搜词根 → 相关查询 → 飙升（Rising），依次看过去 7 / 30 / 90 天；候选词再看 12 个月和 5 年曲线。季节词按季节提前 1–2 个月准备。
6. **竞品反查**：Semrush / Ahrefs 查同领域 3–5 个站的 Organic Keywords 和 Top Pages，找 content gap；traffic.cv 流量暴涨榜每月看一次，再查暴涨站的新增词；没有领域积累就去 whoismaking.money 找公开收入的对标产品。
7. **估量 / 交叉验证**：没有付费工具时用基准词换算；至少交叉验证两个来源（Trends 换算 / Semrush·Ahrefs / Keyword Planner 区间）。中文市场改用百度指数、360 趋势、头条指数和各平台联想词。
8. **建表**：约 50 个候选词，补全搜索量（注明来源）、KD、趋势、相关度、CPS、CPC。
9. **打分选词**：按场景门槛选出 5 个核心词，其余作为长尾储备。
10. **逐个做 Top-10 SERP 分析**：按下方七条规则 + 广告密度 + 能否超越，每个词写成一行记录。
11. **意图 → 页面类型 → 一页一词规划表**：检查主词去重、Parent Topic 合并、slug 反映关键词、每个产品功能至少有一个"把功能翻译成搜索问题"的页面。
12. **持续跟踪**：给核心词设排名追踪（GSC 效果报告或排名工具），每周记录一次；至少坚持一个季度。

## 关键数字与门槛
| 指标 | 门槛/建议值 | 说明 |
|---|---|---|
| KD（新站方向，DR≈0） | < 20 | 约等于进前 10 只需不到 10 个外链 |
| 月搜索量（新站方向） | > 500 | 接近 0 的直接放弃（等于自己教育市场） |
| 相关关键词数（新站方向） | > 100 | 方便以后扩展页面 |
| KD（已有产品 5 个核心词） | < 50（理想） | 有 DR 20–40 外链基础后再碰 KD 30–50 |
| 月搜索量（核心词） | ≥ 1,000（理想） | 与产品高度相关 |
| 文章 / 长尾选题 | 不设硬门槛，可低到几十 | 意图明确、Top 3 单薄；选题 5 问至少 3 项通过（见 04 章） |
| "差一口气"的词 | 平均排名约 11–30 | 有曝光，最容易推上去 |
| CPS | < 1 降低优先级 | 经验判断，原文只给了定义 |
| 商业价值 | CPC × 日访问 | 例：$0.5 × 100 次/天 ≈ $50/天；实际收入达不到说明付费转化要优化 |
| Trends 窗口 | 7 / 30 / 90 天找新词；12 个月 + 5 年验方向 | 越新机会越大 |
| Trends 同次对比 | 最多 5 个词 | 地区、时间范围一致；基准词不能是多义词 |
| 候选池 → 核心词 | 约 50 → 5 | 其余做长尾储备 |
| 起量期 | Google 通常约 3 个月 | 两天没排名不要放弃 |
| Semrush 免费版 | 每天约 10 次查询 | 价格以官网为准 |

## 模板与示例
**词根法**
```text
通用词根：generator / maker / editor / converter / remover / checker / tool / free / online / ai / template
主题词  ：image / poster / video / pdf / logo / voice / resume ...
组合示例：ai image editor / ai image generator / free ai image maker / pdf to excel converter
```

**基准词换算搜索量**
```text
估算搜索量(目标词) ≈ 基准词搜索量 × (目标词 Trends 指数 ÷ 基准词 Trends 指数)
例：tts ≈ 280k/月；ai image editor 指数约为 tts 的 1/6 → ≈ 47k/月（Semrush 约 50k）
```

**Top-10 SERP 七条规则（+2）**
| # | 看什么 | 信号 → 结论 |
|---|---|---|
| 1 | 排名站构成 | 全是大品牌 → 避开；大小站混排 → 可做；很多不知名小站 → 高质量机会 |
| 2 | 是否对口 | 前 10 有明显不是为该词写的页面 → 精准页面能挤进去 |
| 3 | 论坛结果 | Reddit / Quora 在前 5 → 需求没被满足，适合独立站 |
| 4 | Top 3–5 是否专门为该词写 | Title 含完整关键词、H1 直接命中、目录围绕它；否则可写更聚焦的页面 |
| 5 | 是否真正解决问题 | 看步骤、对比、场景、结论，不看字数；又长又空靠"老页面 + 外链"撑着 → 可超越 |
| 6 | 页面类型 | 必须与 SERP 主流类型一致 |
| 7 | SEO 农场特征 | 模板化标题、结构雷同、无作者无案例 → 改打更长尾的词 |
| + | 顶部广告数量 | 广告多 → 付费竞争激烈，优先选广告少的词 |
| + | 能否成为第一 | 列出更好的维度（深度、数据、工具、时效、案例） |

**意图 → 页面类型**
| 意图 | 典型查询 | 应做页面 |
|---|---|---|
| 交易 / 工具 | `pdf to excel`、`remove watermark` | 产品页 / 工具页（打开即用） |
| 教程 | `how to convert bank statement pdf to excel` | How-to 文章，产品是其中一步 |
| 对比 / 选型 | `best …`、`X vs Y`、`X alternatives` | 对比页 / 替代品页（表格 + 诚实结论） |
| 问题排查 | `X not working` | 原因 → 修复步骤文章 |
| 场景方案 | `text to speech for faceless youtube channel` | 场景落地页或文章 |
| 导航 / 品牌 | `yourbrand login` | 首页、登录页，确保品牌词第一是自己 |

**一页一词规划表**
| 主关键词 | 意图 | 月搜索量（来源） | KD | 趋势 | SERP 结论 | 页面类型 | 目标 URL | Parent Topic / 合并到 | 次要词 | 状态 |
|---|---|---|---|---|---|---|---|---|---|---|
| instagram poster size | 信息 | 1.9k（Ahrefs） | 8 | 平稳 | 清单 + 论坛，Top 3 很薄 | 指南文章 | `/blog/instagram-poster-size` | — | instagram post dimensions | 写作中 |

**竞品词页面**：`/alternatives/<竞品>`（为什么找替代 → 对比表含自己 → 诚实结论）、`/compare/x-vs-y`、`/blog/free-x-alternatives`、`/blog/x-coupon`、带年份盘点（每年真的更新内容）。

**功能 → 搜索问题**：批量生成 → how to generate posters in bulk；高清导出 → poster resolution for printing；商用授权 → can ai-generated posters be used commercially。

## 常见错误与过时做法
- ⚠️ 凭灵感选题、不查数据 → 写了没人搜。
- ⚠️ 只看搜索量不看 SERP → 拿产品页拼教程 SERP，永远排不上。
- ⚠️ 新站直接打 KD 60+ 大词 → 半年没有排名；从 KD < 20 和长尾开始积累。
- ⚠️ 多个页面争同一个词 → 排名来回跳；维护规划表并按 Parent Topic 合并。
- ⚠️ 追一次性热点（如当年的指尖陀螺）→ 看 5 年趋势。
- ⚠️ 两天没排名就放弃 → 至少坚持一个季度，持续补内容和外链。
- ⚠️ 混用不同工具的 KD / 搜索量做比较。
- ⚠️ **2026 更新**：纯定义类查询被 AI 概览截流，信息类内容的主要目的变成"被 AI 引用"（见 06 章）。
- ⚠️ **2026 更新**：对比页要写真实信息，不贬低竞品，不冒用对方商标做标题党；优惠页只写能核实的信息。AI 搜索更愿意引用中立、有对比表、写明"什么情况下不适合用我们"的内容。
- ⚠️ **2026 更新（程序化 SEO）**：Google 2024 年 3 月把"规模化内容滥用"写进垃圾政策；程序化页面每一页都要有独立价值（真实工具、真实数据、独特示例），只换关键词套模板可能整站降权。
- ⚠️ 带年份的盘点只改标题年份不改内容。
- ⚠️ 原文工具价格（如 Semrush $99.95/月起、Ahrefs $99/月起）是快照，以官网为准。

## 交付格式
1. **结论先行**：一句话给出推荐的 5 个核心词和首个要做的页面。
2. **候选词评分表**（按优先级排序）：

| 优先级 | 关键词 | 意图 | 搜索量（来源） | KD | 趋势 | SERP 结论 | 页面类型 | 进前 10 可能性 | 依据 |
|---|---|---|---|---|---|---|---|---|---|

   - 优先级用 P0（立刻做）/ P1（本月）/ P2（储备）。
   - "进前 10 可能性"用 高 / 中 / 低 + 主观概率区间表达，并写明依据（KD、SERP 构成、站点 DR）；明确标注这是估计，不是保证。
3. **一页一词规划表**（可直接复制到表格工具）。
4. **SERP 分析记录**：每个核心词一行（排名站构成 / 对口程度 / 论坛 / 专门页 / 页面类型 / 农场特征 / 结论）。
5. **数据可信度说明**：哪些数字来自用户提供的工具、哪些是 Trends 换算或估计、哪些需要用户补查。
6. **下一步**：最多 3 个动作 + 复查时间（例如每周记录排名，一个季度后复盘）。
