# 数据统计与 SEO 工具箱

> 一句话：帮用户选对统计和 SEO 工具、搭好每周 / 每月仪表板，并按固定流程排查流量下跌和不收录。完整内容见仓库 `handbook/11-analytics-and-tools.md`（ArcueidShiki/seo）。

## 何时使用

- 用户要给网站接统计，问 GA4、Plausible、Umami、Clarity、百度统计怎么选
- 用户要配置 Google Search Console、Bing Webmaster Tools、百度搜索资源平台
- 用户要一份每周 / 每月该看的 SEO 与增长指标仪表板
- 用户看不懂 DR、KD、Volume、CPS、Parent Topic 等指标，或问"DR 多少算好"
- 用户的自然流量突然下跌，或新页面不收录、GSC 显示"未编入索引"

## 核心原则

1. 最低配置 GSC + GA4（都免费）；面向中国大陆再加百度统计；注重隐私或面向欧盟用 Plausible / Umami；排查转化再加 Clarity 热力图和录屏。
2. 接入四检：每个页面模板都加载脚本、脚本异步不伤 Core Web Vitals、注册 / 试用 / 付款配置为转化事件（GA4 Key events）、GA4 与 GSC 已关联。
3. 站长后台：GSC 用域名资源验证并提交 sitemap；Bing 可从 GSC 一键导入并支持 IndexNow；面向国内用户必做百度搜索资源平台。
4. DR 是"外链健康报告"不是 KPI；真正的 KPI 是关键词排名、自然流量和转化。独立开发者 DR 20–40 已有竞争力，里程碑 10 → 20 → 30–40。
5. DR 是结果、RD（引用域名）是过程；DR / 外链突增反而不自然，多半是批量买链。
6. KD 各工具算法不同不可横比；新站起步 KD < 20，宽松上限 < 50；Volume ≥ 500（Postma）或 ≥ 1000；CPS 明显 < 1 降低优先级。
7. Parent Topic 与目标词不同时，优先在 Parent Topic 页面覆盖，不新开页面；Organic Traffic 是估算值，只看量级。
8. 每周约 30 分钟看 GSC 效果、排名 11–30 的词、未编入索引、渠道会话、转化；每月约 1–2 小时看 DR / RD、锚文本、品牌词、CWV、留存、单次访问收益、AI 引用。
9. CWV 真实用户阈值：LCP ≤ 2.5 秒、INP ≤ 200 毫秒、CLS ≤ 0.1。
10. 流量下跌先确认是真跌（GSC 与 GA4 同跌、脚本没掉、非节假日），再区分"展示跌"（排名或收录问题）和"展示不跌但点击跌"（CTR 问题）。
11. 新页面不收录：请求编入索引后最多等 1–2 周；需要至少 1–2 条来自已收录页面的内链。
12. 不以骗过 AI 检测器为目标；加入一手经验、截图、数据和明确结论。

## 操作流程

1. **收集信息**：站点类型（工具站 / 内容站 / SaaS）、目标市场（全球 / 欧盟 / 中国大陆）、技术栈与是否用 Cloudflare、已接入的工具、能否提供 GSC / GA4 导出数据、具体问题类型。
2. **按问题分流**：选型接入 → 第 3 步；仪表板 → 第 4 步；流量下跌 → 第 5 步；不收录 → 第 6 步；指标解读 → 第 7 步；反链 → 第 8 步。
3. **选型与接入**：给出工具组合（最低配置 / 隐私优先 / 排查转化），列出接入四检与各站长后台的必做项，提醒 GDPR 地区使用 GA4 需做 Cookie 同意。
4. **搭仪表板**：按"每周 / 每月"模板输出表格；如用户给了数据，逐项填入并标红异常，写出对应动作。
5. **流量下跌排查**：严格按 8 步流程（确认真跌 → 对齐时间点 → 拆维度 → 判断哪个指标跌 → 查收录 → 查处罚安全 → 查技术 → 看竞品），每步写结论与证据。
6. **不收录排查**：按 5 步流程，并对照"未编入索引状态表"给出处理方式。
7. **指标解读**：按"看到 → 先问 → 判断"表逐个解读用户截图或数据里的指标。
8. **反链与竞品**：建议每月用至少一个免费工具记录 RD 新增 / 丢失；用 `"example.com" -site:example.com` 加时间筛选找提及；列出竞品外链中用户也能拿到的（目录、发布站、文章）。
9. **工具推荐**：按用途（流量查询 / 反链 / DR / App / 内容 / 体检）给 1–3 个工具，注明免费额度，中国市场查百度数据用爱站 / 站长之家。

## 关键数字与门槛

| 指标 | 门槛/建议值 | 说明 |
|---|---|---|
| 独立站 DR | 20–40 已有竞争力 | 里程碑 10 → 20 → 30–40 |
| 新站 KD | < 20（宽松上限 < 50） | 不同工具 KD 不可横比 |
| Volume | ≥ 500（Postma）/ ≥ 1000 | 还要看 Clicks |
| CPS | 明显 < 1 降优先级 | 推断阈值 |
| LCP / INP / CLS | ≤ 2.5 秒 / ≤ 200 毫秒 / ≤ 0.1 | 真实用户数据 |
| 留存 D1 / D7 / D30 | ≥ 40% / 20% / 10% | 每月看 |
| 单次自然访问收益 | ≥ 核心词平均 CPC | 收入 ÷ 自然会话 |
| "差一点上首页"的词 | 排名 11–30 且有展示 | 每周优先优化 |
| 新页收录等待 | 请求后最多 1–2 周 | 需 1–2 条内链 |
| 每周复盘 | 约 30 分钟 | 每月约 1–2 小时 |
| Semrush 免费 | 约 10 次 / 天 | 留给最重要的竞品 |
| Moz Link Explorer | 10 次 / 天，每次 50 行 | 免费 |
| Screaming Frog 免费版 | 500 URL | 全站爬取 |
| FrogDR | 免费监控 3 个站 | DR 监控 |
| 竞品规模 | SERP 前 3–5 名 | 记录月访问与渠道 |
| 趋势判断 | Trends 近 12 个月 / 5 年平稳或上升 | 单一尖峰不做 |

## 模板与示例

**每周仪表板（约 30 分钟）**

| 指标 | 数据源 | 目标 / 阈值 | 异常时的动作 |
|---|---|---|---|
| 自然点击、展示、CTR、平均排名（周环比） | GSC 效果 | 趋势向上 | 按页面 / 查询 / 国家 / 设备拆分 |
| 新出现的查询词 | GSC 查询 | — | 补 FAQ / 段落或新开长尾页 |
| 排名 11–30 且有展示的词 | GSC 筛选 | — | 内链 + 补内容 |
| 已发现 / 已抓取未编入索引 | GSC 网页 | 逐周下降 | 改进质量和内链，提交 sitemap |
| 各渠道会话 | GA4 | — | 加大正在涨的渠道 |
| 注册 / 试用 / 付费 | GA4 Key events | 周环比 | 查落地页和结账漏斗 |
| 发布平台引荐（发布后 30 天） | GA4 引荐 | — | 有效平台下次发版重发 |
| 社交：X 曝光粉丝、小红书 CTR ≥ 5%、抖音完播与搜索播放 | 各平台后台 | 见社交章节 | 换封面、改标题、调节奏 |

**每月仪表板（约 1–2 小时）**

| 指标 | 数据源 | 目标 |
|---|---|---|
| DR、RD 新增 / 丢失 | FrogDR / Ahrefs / Moz | RD 稳步增长、无突增 |
| 锚文本分布 | Ahrefs Anchors | 品牌词 / URL 占多数 |
| 品牌词展示量 | GSC（查询含品牌名） | 上升 |
| Core Web Vitals | GSC / PageSpeed | 达到上表阈值 |
| 留存 D1 / D7 / D30 | GA4 / 产品分析 | ≥ 40% / 20% / 10% |
| 单次自然访问收益 vs CPC | 收入 ÷ 自然会话 | ≥ CPC |
| 竞品排名与飙升站 | Semrush / Ahrefs / traffic.cv | 每次变化找到原因 |
| AI 搜索引用 | 用 ChatGPT / Gemini / Perplexity 问目标问题 | 品牌被提及或引用 |
| 人工处置、安全问题 | GSC | "未发现问题" |

**未编入索引状态速查**

| 状态 | 处理 |
|---|---|
| 已抓取 - 尚未编入索引 | 加深内容、补一手信息、加内链；薄页面考虑合并 |
| 已发现 - 尚未编入索引 | 加内链、放进 sitemap |
| 重复网页，Google 选择的规范网页不同 | 查内容是否真不同、canonical 目标是否 200、有无循环 |
| 备用网页（有适当规范标记）/ 自动重定向 | 正常；内链直接指向最终 URL |
| 被 noindex 排除 / 被 robots.txt 屏蔽 | 确认是否有意、规则是否误伤 |
| 404 / 软 404 | 修内链或 301；补内容 |
| 服务器错误（5xx） | 查服务器和 CDN / WAF 是否拦截 Googlebot |

**DR 区间（从业者经验）**：0–10 新站 / 10–30 典型独立站 / 30–50 做过系统外链 / 50–70 细分强站 / 70–90 大媒体平台 / 90+ Wikipedia 级。

**工具组合**：个人站最低 GSC + GA4（+ 百度统计）；隐私优先 Plausible 或 Umami；转化排查加 Clarity；已用 Cloudflare 可零成本加 Cloudflare Web Analytics。

## 常见错误与风险

- ⚠️ 把 DR 当 KPI、只看 DR 不看 RD、追求 DR 快速上涨、以为 DR 高就流量大（DR 80+ 可能几乎无流量）。
- ⚠️ 统计脚本掉了却误判为流量下跌；先用 GSC 与 GA4 交叉确认。
- ⚠️ CTR 下跌但排名不变时忽略 AI 摘要分流：AI Overviews / AI Mode 计入 GSC"网页"类型，无法单独筛选。
- ⚠️ 原文把 Fathom 标为开源：开源的只是停止维护的 Fathom Lite，现版本闭源付费。
- ⚠️ `link:` 指令早已不可靠，只能当参考。
- ⚠️ 用 Ahrefs / Semrush 查百度数据：中国市场用爱站 / 站长之家。
- ⚠️ 用 GPTZero 把 AI 分数压到 40% 以下作为发布标准：检测器误判率高，Google 看的是内容是否有帮助。
- ⚠️ 在 GDPR 地区用 GA4 不做 Cookie 同意。
- ⚠️ 工具价格与免费额度为原文快照，可能已变化。

## 交付格式

- 选型：`工具 | 用途 | 免费情况 | 是否推荐 | 理由` 表。
- 仪表板：直接输出可复制的每周 / 每月 markdown 表，填入用户数据并标出异常。
- 排查：按步骤编号输出 `步骤 | 检查项 | 结果 | 证据 | 结论`，最后给出最可能原因排序，用"高 / 中 / 低 可能性"并写依据，不编造精确概率；附 P0/P1/P2 修复清单。
