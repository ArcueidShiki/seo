# 外链建设

> 一句话：帮用户把外链当成第三方"信任票"来建——证明产品真实存在、帮搜索引擎把它归到正确类目、带来会转化的真实用户，而不是去刷 DR。完整内容见仓库 `handbook/05-backlinks.md`（ArcueidShiki/seo）。

## 何时使用
- 产品刚上线，用户问"外链从哪里开始""先提交哪些目录"
- 用户要评估一条外链、客座文章或链接交换值不值得做
- 用户问 DR 多少算好、DR 为什么不涨、要不要买外链
- 用户要拆解竞品上线后 0–30 天的冷启动外链
- 用户要检查锚文本分布、外链增速，或担心有毒外链 / 要不要 disavow
- 用户要一张外链追踪表或月度复盘

## 核心原则
1. **外链放大的是已有基础**：技术 SEO 和页面优化（02、03 章）没做好之前，不要大规模建外链。
2. **目标是信任和归类，不是 DR**：每条链接最好至少满足一条——带来注册、有真实点击、在社区里长期可见。
3. **分阶段**：第 0–1 个月建立信任（目录 + 发布平台 + 少量社区，来源类型尽量分散）；第 1–3 个月强化语义（场景文章、可引用资产、builder story、对比 / 替代品页）；3 个月后让外链越来越多来自"被提到"。
4. **评估链接四要素一起看**：DR / 权威度、相关性（主题相关 > 受众相关）、真实自然流量、是否 dofollow。
5. **三个细节**：位置放正文最好（页脚、侧边栏全站链接、论坛签名几乎没权重）；自然不突兀；锚文本给出明确语境。
6. **DR 是结果，RD 是过程**：独立开发者 DR 20–40 就很有竞争力，里程碑 10 → 20 → 30–40；真正的 KPI 是关键词排名、自然流量和转化。
7. **DR 70 却无流量无用户的链接农场，价值可能不如 DR 25 的垂直博客**；高度相关、能带流量的 nofollow 链接照样值得做，用引荐会话数衡量。
8. **冲刺顺序**：先 DR 高的发布平台，再 dofollow 且 DR ≥ 50 的目录（第一轮至少 10 条）；AI 产品要覆盖主要 AI 目录；中文社区为流量不为权重。
9. **付费的边界**：花钱买"审核收录 + 曝光 + 归类"且目录本身有真实用户 = 正常营销支出；花钱买传递 PageRank 的链接（PBN、链接农场、按 DR 卖的客座文章、批量链接包）= 违反链接垃圾政策。判断问题：如果这个网站对 Google 完全不可见，你还愿意花这笔钱吗？
10. **锚文本以品牌词、裸 URL、自然语句为主**，精确匹配关键词只占少数（≤ 5–10%）；站内链接正好相反，用描述性关键词锚文本。
11. **增长要平稳**：RD 曲线出现尖峰看起来不自然。
12. **所有 DR、rel、价格都是快照**：提交后在线上 listing 页实测 `rel`；90 天没带来点击的来源，下次降低优先级。

## 操作流程
1. **收集输入**：产品类型（是否 AI 工具）、上线日期与阶段、当前 DR / RD（Ahrefs、GSC 链接报告）、预算、目标市场（英文 / 中文）、技术和页面优化是否到位、已提交过的平台。
2. **判阶段、选打法**：按 0–1 / 1–3 / 3+ 个月给出本阶段动作和指标（收录页数、listing 数、RD、引荐流量、长尾排名、品牌词展示、自然获得 RD 占比）。
3. **出提交清单**：发布平台 + 综合目录 + AI 目录 + 中文社区，每行带 DR、rel、价格、备注；描述不要用模板，类目选对，优先选显示上线和更新日期的平台。
4. **付费决策**：先算 DR / 美元，再看对方自然流量 > 0 且稳定；确认付费 listing 是否 dofollow；定固定预算（例如上线时约 $100 花在"≤ $30、DR 70+"这一档）；$299–599 的高价目录只在能带来真实流量时考虑。
5. **评估单条链接**（客座、交换）：四要素 + 三细节逐项打分，给"做 / 不做"结论。
6. **竞品冷启动分析**（用户要求时）：按下方 7 步取证，工具只兜底验证；按"≥ 2 条标准"判定核心冷启动链接；整理成带日期的路径，再给用户排自己的发布计划。
7. **锚文本审计**：用 Ahrefs Anchors 对照分布区间，指出过度优化。
8. **建追踪表并每月复盘**：RD 增长、新增 / 丢失外链、按来源的引荐会话和注册数。
9. **外包提交**：要求对方交付上线后的 listing URL 清单，至少抽查 20%。
10. **异常处理**：只有遭到人工处置或突然多出一批有毒外链时才考虑 disavow。

## 关键数字与门槛
| 指标 | 门槛/建议值 | 说明 |
|---|---|---|
| DR 目标（独立开发者） | 20–40 | 里程碑 10 → 20 → 30–40 |
| DR 区间（经验划分） | 0–10 新站 / 10–30 小站 / 30–50 系统建过外链 / 50–70 细分强站 / 70–90 大媒体平台 / 90+ 维基百科级 | 0–100 相对分数，只算 dofollow，Google 不用 |
| 第一轮目录 | dofollow 且 DR ≥ 50，至少 10 条 | 先做 DR 高的发布平台 |
| 上线预算示例 | 约 $100，买 ≤ $30、DR 70+ | 记录花费与收获 |
| 高价目录 | $299–599 | 仅在能带来真实流量时 |
| 点击率差距（原文引用） | 第 1 名约 27.6%，约为第 10 名的 10 倍 | 外链影响排名的理由之一 |
| 冷启动窗口 | 上线后 0–30 天，找 5–20 条链接或提及 | 也可放宽到 Day 0–60 |
| 三类信号比例 | 直接外链 : 只提 URL : 只提名字 ≈ 2 : 4 : 4 | 三类都要找 |
| 换引擎补查 | Bing、DuckDuckGo 通常多找回 10–20% | 历史残留不同 |
| 冷启动找回目标 | 约 70% | 弄清谁第一个背书 |
| 锚文本分布（经验值） | 品牌 40–60% / 裸 URL 15–25% / 通用 10–20% / 部分匹配 10–15% / 精确匹配 ≤ 5–10% | 原文只说精确匹配占少数 |
| 外包抽查 | ≥ 20% | 确认在线且指向你 |
| 低效来源 | 90 天无点击 → 降优先级 | 每月复盘 |
| Uneed | $29.99；当日第一约需 40–50 票 | 免费发布要排很久 |

```text
Step 4  site:producthunt.com "Product Name"   site:reddit.com "Product Name"
        site:news.ycombinator.com "Product Name"   site:indiehackers.com "Product Name"   site:betalist.com "Product Name"
Step 5  Wayback 最早 2–3 个快照里的 "Featured on" / "As seen on" / 发布徽章
Step 6  Bing、DuckDuckGo 再查一遍
Step 7  Ahrefs / Semrush（及自己的 GSC）验证、补充仍存活的链接

```

## 常见错误与过时做法
- ⚠️ 从第一天就追 DR；把 DR 当 KPI；只看 DR 不看 RD；以为 DR 涨得越快越好。
- ⚠️ 锚文本过度优化（大量精确匹配关键词）；只提交同一类目录，来源单一。
- ⚠️ 购买"看起来像 SEO"的链接：PBN、链接农场、批量外链包、按 DR 卖的客座文章；拿和产品无关网站的链接。
- ⚠️ 短时间外链暴涨；自己批量制造对比 / 替代品类链接（第三方提到才最有价值）。
- ⚠️ 在 Reddit 发裸链接、刷 karma——Reddit 适合获取用户和验证需求，不要指望 SEO 外链。
- ⚠️ 灰帽 / 黑帽：伪造来路的 referrer spam、蹭别人品牌名、买赞冲评论区，都有平台规则或法律风险。
- ⚠️ 判断标准：一个在 2015 年看起来很合理的外链手法，到 2026 年很可能是有毒的。
- ⚠️ **2026 更新**：`link:` 指令 2017 年已被 Google 停用，`domain:` 也不是 Google 支持的指令；查外链用工具和 GSC 链接报告。
- ⚠️ **2026 更新（文档冲突）**：《外链建设策略》说不要买像 SEO 的链接，《付费外链资源》又列付费目录——按核心原则第 9 条的边界处理。
- ⚠️ 两篇原文价格不一致（如 aitools.fyi $197 vs $30、WhatsTheBigData $599 vs $499），一律以官网为准。
- ⚠️ AppSumo 这类买断制渠道主要换现金和曝光，不是为了外链。

## 交付格式
1. **结论先行**：当前阶段 + 本月最该做的 3 件事。
2. **外链计划表**（按优先级排序）：

| 优先级 | 资源 | 类型 | DR | rel（待实测） | 成本 | 预期价值（流量 / 归类 / 权重） | 风险 | 备注 |
|---|---|---|---|---|---|---|---|---|

   P0 = 本周提交；P1 = 本月；P2 = 视预算。付费项写明"DR / 美元"和对方自然流量证据。
3. **单条链接评估**：四要素 + 三细节打分表，结论"做 / 不做 / 观望"，并给出"带来真实点击的可能性 高 / 中 / 低"及依据。
4. **竞品冷启动报告**：路径表 + 可复用的带日期发布计划 + 找回率估计。
5. **复盘指标**：RD 变化、新增 / 丢失外链、按来源的引荐会话和注册数；所有 DR 和价格注明"快照"。
