# 发布与冷启动：获客渠道、发布平台与内容引流

> 一句话：把"产品上线后第一批用户从哪来"变成一份排好优先级的发布计划、素材包和引流漏斗。完整内容见仓库 `handbook/07-launch-and-distribution.md`（ArcueidShiki/seo）。

## 何时使用

- 用户产品即将上线或刚上线，问"第一批用户从哪来""先做哪个渠道"
- 用户要在 Product Hunt、Hacker News（Show HN）、Uneed、BetaList、AI 导航站、V2EX 等平台发布
- 用户要准备发布素材包（Slogan、介绍、截图、视频、FAQ）或逐项过上线 TodoList
- 用户在评估某个付费导航站 / 目录站值不值得买
- 用户想用内容把流量导回产品或私域，或要做品牌 / 个人品牌定位

## 核心原则

1. 先低成本后付费：目录与发布平台、SEO、联盟 → 社交与内容 → KOL → 付费广告；付费投放是上线清单第 20 步，即最后一步。
2. SEO 和社交从第一天并行，各设一个周 KPI（社交看曝光 / 粉丝，SEO 看 GSC 点击）；SEO 约 3 个月起量。
3. 不必 6 个杠杆全做，按"1 主 + 2 辅"写成书面计划：主渠道每周有量化目标，辅渠道只做维护。
4. 付费前过两道门槛：留存 D1/D7/D30 ≥ 40%/20%/10%，且单次访问收益 ≥ 关键词 CPC。
5. 导航站付钱前先查真实流量（Similarweb / Ahrefs）并确认链接是 dofollow；$10–30 拿 DR 70–82 那一档最划算，$299–599 只有带来真实流量才值。
6. V2EX、知乎、掘金、少数派、Linux.do 和 Linktree 的链接基本是 nofollow：算流量渠道，不算外链 KPI。
7. PH / HN 不求赞、不刷票、不搞互赞群；Show HN 必须能直接试用，一次没起来不要反复重发。
8. 内容配比 80% 对用户有用 / 10% 产品 / 10% 个人生活；一个账号只做一个垂直方向。
9. 跨平台转载：先在自己站发布并等收录，转载页设 canonical 指回原文，或只转前 70% 再链回。
10. 坚持阈值：10–20 篇看不出效果，同一垂直写到 500–1000 篇一定会有效果。
11. 留存优先：留存差时任何获客都留不住，停投后用户就流失。
12. 程序化批量页每页必须有真实功能、数据或示例，否则触发 Google 规模化内容滥用（2024 年 3 月起）。

## 操作流程

1. **收集信息**：产品类型（Web / App / 开发者工具 / AI 工具）、目标市场（海外 / 国内 / 两者）、阶段（beta / 已上线 / 已有付费）、现有渠道与粉丝量、预算、留存与付费数据（若有）、计划上线日期。
2. **判断阶段**：对照留存 4-2-1 与"单次访问收益 vs CPC"，决定是否允许进入 KOL / 付费阶段；未达标只排低成本渠道，并写明原因。
3. **排渠道**：用"六杠杆优先级"表给出 1 主 + 2 辅，每个渠道写周 KPI 与启动时间。
4. **过上线 TodoList**：按 A–F 六组 20 步逐项标注 已完成 / 未完成 / 阻塞，重点检查 GSC / GA4 / Bing 是否在流入数据、支付是否端到端测过、Stripe webhook 是否被 Cloudflare 拦截。
5. **产出发布素材包**：10 项素材 + 1200×630 OG 图，直接给出 Slogan、简短介绍、3–5 条亮点、适合 / 不适合谁、FAQ 的草稿。
6. **挑平台**：按产品类型从"综合发布平台 / AI 导航站 / 国内平台"三类中挑选，标注免费 / 付费、DR、是否值得付费；海外 AI 产品优先 PH + 低价高 DR 导航站，开发者工具加 HN / DevHunt / Peerlist，beta 阶段先 BetaList。
7. **排节奏**：按"发布节奏"模板给出 Day 0 到第 3 月的日历，并预留每次大版本的重发动作。
8. **PH / Show HN 专项**（如适用）：给出 T-14 / T-7 / 上线日 / 发布后动作表，写好 Maker 首评或 Show HN 首条评论草稿。
9. **设计引流漏斗**：公域内容 → 主页置顶 → 落地页 → 私域 → 付费，每层给做法和指标；国内平台用主页简介和置顶承接，正文不出现导流话术。
10. **品牌**（如用户问到）：写一句品牌价值陈述，用"兴趣与深度 / 价值 / 一致性 / 差异化"四项自检个人品牌。

## 关键数字与门槛

| 指标 | 门槛/建议值 | 说明 |
|---|---|---|
| 留存 D1 / D7 / D30 | ≥ 40% / 20% / 10% | 付费获客与 KOL 的前置门槛 |
| 单次访问收益 | ≥ 核心关键词 CPC | 同上 |
| SEO 起量 | 约 3 个月 | 第 1 天就开始 |
| 渠道结构 | 1 主 + 2 辅 | 主渠道每周量化目标 |
| Uneed 当日第一 | 约 40–50 票 | 免费排队久，$29.99 可快速上线 |
| 高性价比导航站 | $10–30 → DR 70–82 | 如 Startupfa.me、Uneed、Dang.ai |
| 简短介绍 | 中文 100–300 字 / 英文 50–100 词 | 第一句讲结果 |
| 宣传图 | 约 5 张 | 第一张直接讲核心价值 |
| 宣传视频 | 1–2 分钟，开头 5 秒展示结果 | 嵌到首页 |
| 核心亮点 | 3–5 条 | 每条对应一个痛点 |
| OG 图 | 1200×630 | 社交分享卡片 |
| PH 日界 | 美国太平洋时间 00:01 起算 24 小时 | 尽量 00:01 上线 |
| PH 评论 | 24 小时内全部回复 | 原文要求 |
| 内容配比 | 80 / 10 / 10 | 有用 / 产品 / 个人 |
| 一稿多发 | 每篇 ≥ 3 个渠道 | 短文 / 图文 / 视频 / 音频 |
| 坚持 | 500–1000 篇 | 10–20 篇看不出效果 |
| 个人品牌一致性 | 近 30 天 ≥ 80% 内容在声明领域 | 能否写出 100 个选题 |
| 私域估算 | 2 万好友 × 1% × ¥200 ≈ ¥4 万 | 代入自己的转化率 |

## 模板与示例

**六杠杆优先级**

| 优先级 | 杠杆 | 成本 | 起效 | 何时启动 |
|---|---|---|---|---|
| 1 | 目录 / 发布平台 / 科技媒体 | 低 | 快（发布日一波） | 第 0–1 月 |
| 1 | SEO（每个功能 / 工具词一个页面） | 低 | 慢（约 3 个月） | 第 1 天 |
| 1 | 联盟营销（Impact、ShareASale 等） | 低（按效果） | 中 | 有稳定付费转化后 |
| 2 | 社交媒体（自然数据好的帖子再付费加热） | 中（时间） | 中–快 | 第 1 天起并行 |
| 3 | KOL / KOC（CPA / CPS / 月度包干） | 中–高 | 快 | 留存、付费率验证后 |
| 4 | 付费广告 | 高 | 最快 | 最后 |

**上线 TodoList（20 步，按顺序）**

```
A 基础设施  1 SEO 标签(title/description/canonical/OG/唯一 H1)
            2 页面结构 Hero→痛点→方案→步骤→案例→对比→FAQ→CTA
            3 GSC + GA + Bing 接入并确认数据流入   4 域名邮箱 MX/SPF/DKIM/DMARC
            5 支付端到端测试，砍多余步骤
B 发布准备  6 宣传图与文案   7 1 主 + 2 辅渠道书面计划   8 内容更新频率
C 发布外链  9 PH / Show HN   10 目录站、发布站、社交主页、博客外链   11 Affiliate 计划
D 用户迭代  12 社群 + 反馈入口   13 changelog   14 长尾词专页（关键词→URL 映射表）
E 持续增长  15 buildinpublic 晒数据   16 演示视频   17 教程 / 博客
            18 访谈第一个付费用户   19 按访谈调价
F 放大      20 以上全部完成后才开始付费投放
```

**Show HN**

```
标题：Show HN: 产品名 – 一句话说明它做什么   （无形容词堆砌、无感叹号）
首评：做这个的背景 / 技术实现 / 目前局限 / 最想得到哪类反馈
```

**发布节奏**

| 时间 | 动作 | 作用 |
|---|---|---|
| Day 0–1 | PH / HN / V2EX / Reddit 社区发布 | 第一波曝光和反馈 |
| Day 3–7 | 邀博主写测评；写"我如何用 X 在 N 分钟做完 Y" | 承接搜索长尾 |
| Day 7–14 | 导航站、推荐清单、目录站集中提交 | 引荐流量 + 让搜索引擎归对类 |
| 第 1–3 月 | 场景文章、用例、模板 / 提示词库 / 参数表 | 语义强化，拿长尾排名 |
| 每次大版本 | PH relaunch、目录更新、社群帖 | 留下新的提及记录 |

**内容引流漏斗**

```
公域内容 → 个人主页(置顶产品帖 + 简介链接) → 落地页 / 博客 / 公众号
        → 私域(微信 / 邮件列表 / Telegram / Discord) → 付费(会员 / 专栏 / 课程 / 订阅)
```

## 常见错误与风险

- ⚠️ 爬竞品关键词批量生成模板页：属于 Google 规模化内容滥用，可能整站降权。
- ⚠️ PH / HN 求赞、刷票、互赞群、投票环：会被识别后降权或沉底。
- ⚠️ Show HN 只放落地页、等待名单或强制注册：容易被标记或冷落。
- ⚠️ 付费导航站不查真实流量、不查 `rel` 属性：有些目录把 dofollow 当付费升级项卖。
- ⚠️ 把 nofollow 社区算进外链 KPI，导致误判外链进度。
- ⚠️ 小红书、抖音正文出现二维码、网址、"私信领取"：轻则单篇、重则整号限流。
- ⚠️ 全文转载且不设 canonical：转载页可能抢走原文排名。
- ⚠️ 灰 / 黑帽手法不要做：伪造来源访问（referrer spam）、蹭知名品牌名注册公众号、买赞把评论或回答顶上去。
- ⚠️ 留存未达标就投放或找 KOL：停投即流失。
- ⚠️ AppSumo 等买断制推广不先算毛利。
- ⚠️ 平台流量、DR、价格是原文快照，会变化，提交前复核。

## 交付格式

- 开头一句结论：当前阶段判断 + 推荐主渠道 + 是否允许付费。
- 主表：`优先级(P0/P1/P2) | 渠道 / 平台 | 具体动作 | 成本 | 预期起效时间 | 周 KPI | 启动日期`。
- 附表：上线 TodoList 缺口（已完成 / 未完成 / 阻塞原因）、素材包草稿、发布日历。
- 对效果用概率框架表述（高 / 中 / 低 可能性 + 依据，如"取决于预热粉丝量"），不编造精确数字；引用的平台数据注明"原文快照"。
