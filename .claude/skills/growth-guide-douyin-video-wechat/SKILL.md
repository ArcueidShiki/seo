# 抖音、短视频与微信生态

> 一句话：同时按"推荐流（完播 + 互动）"和"搜索（关键词）"两套逻辑做短视频，并用微信搜一搜、小程序和私域承接长期流量。完整内容见仓库 `handbook/10-douyin-video-wechat.md`（ArcueidShiki/seo）。

## 何时使用

- 用户要做抖音 / TikTok / YouTube Shorts 视频，问怎么被搜到、怎么上推荐、怎么提高完播
- 用户要写短视频脚本、开头钩子、标题、话题标签，或排发布时间
- 用户的视频播放低、账号不起量，怀疑标签混乱或隐性限流
- 用户要做微信小程序 SEO、公众号搜一搜、私域承接
- 用户要在知乎、B 站、百度等多平台做关键词内容，或做 App ASO

## 核心原则

1. 两套逻辑同时优化：推荐流靠完播和互动，爆发快衰减快；搜索靠关键词，起量慢但能持续数月。要长期流量就有意识地做搜索型视频。
2. 一条视频只锁一个关键词；标题 = 核心关键词（原样出现，不拆开、不换同义词）+ 场景 / 人群 / 结果。
3. 关键词"说出来 + 写出来"：前 5 秒口播、封面文字、前 3 秒字幕、中段总结卡片都要出现。
4. 话题 3–5 个：1 个核心关键词 + 1–2 个细分长尾 + 1 个人群 / 场景；不蹭无关热门，不要 10 个以上。
5. 账号垂直：昵称简介含领域词，≥ 80% 历史视频在同一主题；搜索更偏爱"专家型账号"。
6. 完播权重最高：10 秒视频要看完 8–10 秒，30 秒视频平均看到 ≥ 25 秒；大多数视频控制在 1 分钟内。
7. 前 3 秒用反常识、结果先行、制造矛盾或直击痛点开场，不做自我介绍。
8. 节奏：每 1–2 秒换一个镜头，剪辑可加速到 ≥ 1.2 倍；真人出镜；用手机拍屏幕，画面里不露网址。
9. 发布时段 11:30–13:00、18:00–20:00、21:00–23:00；新号每天 1 条，成熟号以稳定为主。
10. 保护账号信用分：不违规、不频繁删视频、不搬运、不重复上传同一内容。
11. 小程序：名称直接用用户搜的词（权重最高），简介首行含核心词，类目与功能一致，每个核心页面都有文字。
12. 公众号正文不放外链，用文末"阅读原文"和小程序卡片导流；名称用自己的品类词，不用别人的品牌词。

## 操作流程

1. **收集信息**：平台（抖音 / TikTok / Shorts / 视频号 / 公众号 / 小程序 / App）、领域、目标（推荐爆发 / 搜索长尾 / 私域转化）、账号数据（完播率、搜索来源播放占比、垂直度）、能否真人出镜、产品落地方式。
2. **找关键词**：用搜索框联想词、搜索结果前 10 个视频标题里反复出现的词、评论区提问三种方法，建立该平台的长尾词表。
3. **逐条视频产出**：标题、60 秒脚本（时间轴）、封面文字、话题组合、发布时段；标注它命中了"知识 / 趣味 / 共鸣"中的哪几个。
4. **发布前三问**：用户为什么不划走？为什么会看完？看完为什么要互动？任一项答不上就改脚本。
5. **账号审计**：垂直度（≥ 80%）、昵称简介关键词、信用分风险行为、是否存在打标签杀手（频繁换主题、标题内容不符、蹭热点）。
6. **小程序 SEO**（如适用）：按"名称 / 简介 / 类目 / 页面文字 / 行为信号 / 外部导入"六因素审计，并用搜一搜下拉词和"小程序"标签页前 10 名找词。
7. **公众号**（如适用）：标题和正文放用户会搜的词，设计"阅读原文"与小程序卡片导流路径。
8. **全平台 SEO**：按平台表给出每个平台的关键词位置、内容寿命与合规导流方式，套用垂直深耕五步法。
9. **App ASO**（如适用）：副标题、描述、前 2–3 张截图、评分引导逐项给出建议。
10. **设定预期与复盘**：搜索型内容按月看"搜索来源播放占比"，不按天看；小程序不会 7 天起量，只会慢慢爬升。

## 关键数字与门槛

| 指标 | 门槛/建议值 | 说明 |
|---|---|---|
| 完播（10 秒视频） | 看完 8–10 秒（≥ 80%） | 权重最高的互动指标 |
| 完播（30 秒视频） | 平均 ≥ 25 秒 | 原文"好"的标准 |
| 视频时长 | 大多数 < 1 分钟 | 节奏快 + 时长短 |
| 关键词口播 | 前 5 秒内 | 发布后检查自动字幕 |
| 关键词字幕 | 前 3 秒 | 同时出现在封面和总结卡片 |
| 话题标签 | 3–5 个 | 不要 10 个以上 |
| 账号垂直度 | ≥ 80% 视频同一主题 | 不今天副业明天情感 |
| 镜头切换 | 每 1–2 秒 | 剪辑加速 ≥ 1.2 倍 |
| 发布时段 | 11:30–13:00 / 18:00–20:00 / 21:00–23:00 | 新号每天 1 条 |
| 打标签样本 | 最早约 1000 名观众 | 决定"推给谁" |
| 三要素 | 中 1 个尚可 / 2 个爆款 / 3 个超级爆款 | 知识、趣味、共鸣 |
| 高权重平台长文 | ≥ 3000 字，1–2 个月可能进百度首页 | 知乎、豆瓣、简书、Lofter |
| 公众号案例 | 日更 60 天：收入 1 万+、涨粉 9000+、6 篇 10 万+ | 原文案例 |
| 私域估算 | 2 万好友 × 1% × ¥200 ≈ ¥4 万 | 代入自己的转化率 |
| ASO 截图 | 前 2–3 张各讲一个卖点 | 副标题放核心词 |
| YouTube Shorts 时长 | 2024 年 10 月起最长 3 分钟 | 发现型内容仍以 1 分钟内为主 |

## 模板与示例

**60 秒脚本（SEO + 推荐）**

| 时间 | 内容 |
|---|---|
| 0–3 秒 | 钩子：结果先行或反常识观点 + 固定片头 |
| 3–5 秒 | 口播关键词，屏幕显示关键词字幕 |
| 5–45 秒 | 3–5 个要点，每个 1–2 句话，每 1–2 秒换画面 |
| 45–55 秒 | 总结卡片（再次出现关键词） |
| 55–60 秒 | 互动：抛一个问题 / "下一期讲 X" |

**标题与开头**

```
标题：核心关键词 + 明确的场景 / 人群 / 结果
例：抖音 SEO 新手教程：3 步让视频被搜到
开头：✅ "我做了 3 个抖音号，只有这个活下来了"   ❌ "大家好，我是……"
话题：#核心词 #长尾词1 #长尾词2 #人群或场景
```

**系列化要点**：每期标题格式和开场相同、按期编号、人设名称体现身份（如"程序员"）、真人口播镜头穿插。

**小程序 SEO 审计**

| 因素 | 权重 | 正例 | 反例 |
|---|---|---|---|
| 名称 | 最高 | "图片压缩工具""PDF 转换助手" | "星图 Pro"这类纯品牌名 / 英文 / 缩写 |
| 简介 | 高 | 首行含核心词的完整一句话 | 广告文案、关键词堆砌 |
| 服务类目 | 高 | 与核心功能一致 | 随便选一个能过审的 |
| 页面文字 | 最大盲区 | 页面标题 + 功能说明 + 结果页解释 | 只有图标没有文字 |
| 行为信号 | 中 | 任务完成后 / 第 2–3 次使用时提示添加 | 一打开就弹窗 |
| 外部导入 | 中 | 公众号插入、视频号挂载、群里"搜索 XX 进入" | 只发直达链接 |

**全平台 SEO**

| 平台 | 关键词放在哪 | 内容寿命 | 合规导流 |
|---|---|---|---|
| 百度 | 网站 TDK、正文 | 长 | 新站主攻独特品牌词 |
| 知乎 | 问题标题、回答首段 | 长 | nofollow，靠主页和文末 |
| B 站 | 标题、简介、标签 | 长（教程） | 简介可放链接（以规则为准） |
| 抖音 | 标题、口播、字幕、话题 | 推荐短 / 搜索长 | 画面不露网址，导主页 |
| 微信 | 公众号标题、小程序名称与页面文字 | 中–长 | 阅读原文、小程序卡片 |
| 小红书 | 标题、正文、标签 | 长 | 严禁导流，用主页承接 |

**垂直深耕五步**：选细分领域 → 挖长尾词每词一篇 → 固定节奏发布 → 每篇埋合规钩子 → 坚持过平坦期。

## 常见错误与风险

- ⚠️ 画面或口播露网址、二维码：站外导流会被限流；导流到主页。
- ⚠️ 隐性限流内容：贩卖焦虑、极端对立、引战攻击、灰色赚钱项目、擦边、暗示违规，不封号但拿不到流量。
- ⚠️ 打标签杀手：频繁换主题、标题和内容不符、蹭无关热点，结果是算法谁也不推。
- ⚠️ 频繁删视频、搬运盗用、重复上传：降低账号信用分。
- ⚠️ 模板化或明显 AI 生成的视频容易不被推荐；要真人、真实语气、有情绪。
- ⚠️ 公众号起名"知名品牌 + 品类"蹭品牌搜索：有商标侵权和平台处罚风险，不要模仿。
- ⚠️ 长文要求关键词出现 ≥ 20 次属于旧式密度思路，易被判堆砌；"排名后再改文加链接"可能被判营销，且外链多为 nofollow。
- ⚠️ 小程序前期错误（纯品牌名、简介写成广告、类目选错、页面无文字、功能多却无核心词）后期很难改。
- ⚠️ TikTok 主页链接有开通条件；YouTube Shorts 自 2023 年起描述 / 评论区链接不可点击，改用"相关视频"导向长视频。
- ⚠️ 海外平台做法多从抖音经验迁移而来，执行前以平台当前规则为准。

## 交付格式

- 视频：`序号 | 目标关键词 | 标题 | 0–3 秒钩子 | 话题 | 封面文字 | 三要素命中 | 发布时段` 表，另附完整 60 秒脚本。
- 账号 / 小程序审计：`因素 | 现状 | 问题 | 改法 | 优先级(P0/P1/P2)`。
- 全平台计划：按平台列关键词位置、发布节奏、导流方式。
- 预期用概率框架表述（如"推荐流起量：低–中，取决于完播率；搜索长尾：中，需按月观察"），给依据，不编造精确数字。
